# ก๊วนแบต — วิธีเอาขึ้น GitHub Pages ให้เปิดในมือถือ

อัปโหลด **ทุกไฟล์เหล่านี้เข้าไปใน repo (ที่โฟลเดอร์ราก)**:
- `index.html` (ตัวแอป)
- `manifest.webmanifest`
- `icon-180.png`, `icon-192.png`, `icon-512.png`, `favicon-32.png` (ไอคอน)
- `.nojekyll` (ไฟล์ว่าง — ให้ GitHub เสิร์ฟไฟล์ไอคอนตรง ๆ)

> ถ้าอัปโหลด `.nojekyll` ไม่ได้ (บางเครื่องซ่อนไฟล์ขึ้นต้นจุด) ข้ามได้ ส่วนใหญ่ยังทำงานปกติ

## ขั้นตอน (ทำครั้งเดียว)

1. เข้า https://github.com → **New repository**
   - ตั้งชื่อ เช่น `badminton` → เลือก **Public** → **Create**
2. ในหน้า repo กด **Add file → Upload files** → ลากไฟล์ `index.html` เข้าไป → **Commit changes**
3. ไปที่ **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / folder: **/ (root)** → **Save**
4. รอ ~1 นาที จะได้ลิงก์รูปแบบ
   `https://<ชื่อบัญชี>.github.io/badminton/`
5. เปิดลิงก์นั้นในมือถือ → กด **แชร์ → เพิ่มไปยังหน้าจอโฮม** จะได้ไอคอนเปิดเหมือนแอป

## ข้อมูลจะไม่หายเมื่ออัปเดต

- ข้อมูล (ผู้เล่น, รูป, ก๊วน, คะแนน, การจ่ายเงิน, QR) เก็บอยู่ใน **เบราว์เซอร์ของเครื่องนั้น** (localStorage) ผูกกับ **URL ของเว็บ**
- เวลาอัปเดตโค้ด: แค่ **Upload files** ทับ `index.html` เดิม (URL เท่าเดิม) → ข้อมูลยังอยู่ครบ

## ข้อควรรู้

- ข้อมูลอยู่เฉพาะเครื่อง/เบราว์เซอร์ที่ใช้ ไม่ sync ข้ามเครื่อง (เหมาะกับคนจัดก๊วนใช้มือถือตัวเอง)
- ถ้า “ล้างข้อมูลเว็บไซต์” ในเบราว์เซอร์ หรือเปลี่ยนเครื่อง/เบราว์เซอร์ ข้อมูลจะไม่ตามไป
- พื้นที่เก็บ ~5MB ต่อเว็บ — รูปโปรไฟล์ถูกย่อให้เล็กแล้ว แต่ถ้าใส่รูปเยอะมากอาจเต็ม
- ต้องมีเน็ตตอนเปิด (โหลด React จาก CDN)
